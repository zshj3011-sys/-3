## 二、密钥 & API 配置 (`.env`)

修改 `medmind-backend/.env.example` 为 `.env`, 替换以下:

| 变量 | 默认值 | 生产必须 | 说明 |
|---|---|:---:|---|
| `APP_DEMO_MODE` | true | 改为 **false** | 关闭演示数据自动播种 |
| `DATABASE_URL` | sqlite:///... | 改为 PG 真实地址 | postgresql+psycopg://... |
| `JWT_SECRET` | dev-secret | 改为**强随机 64 字节** | `openssl rand -hex 32` |
| `LLM_PROVIDER` | mock | 改为 deepseek / qwen / zhipu | 4 选 1 |
| `LLM_API_KEY` | sk-mock | **替换真实 Key** | 客户向模型厂商申请 |
| `LLM_BASE_URL` | (空) | 替换为厂商真实 endpoint | 例 https://api.deepseek.com/v1 |
| `LLM_MODEL` | mock-medical | 改为 deepseek-r1-medical 等 | 按厂商目录 |
| `CORS_ORIGINS` | * | 改为**白名单域名** | 安全要求 |

## 五、数据迁移 / 初始化

```bash
# 1. 切换到 PostgreSQL
export DATABASE_URL="postgresql+psycopg://user:pwd@db:5432/medmind"

# 2. 执行 Alembic 迁移
cd medmind-backend && alembic upgrade head

# 3. (可选) 导入医院字典数据
python scripts/import_dict.py path/to/科室字典.csv

# 4. 创建管理员账号 (不再使用默认 admin123)
python scripts/create_admin.py --username 院长账号 --password '<强密码>'
```

⚠ **必须删除默认演示账号** (admin/admin123, dr_zhang/doctor123 等)
