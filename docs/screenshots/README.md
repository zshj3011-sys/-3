## 备注

- 所有截图分辨率 **1366 × 860**, 96 dpi
- 浏览器: Chromium (Playwright)
- 部分页面顶端的 emoji 在 Linux headless 环境中显示为方框是字体问题, 在 Windows / macOS / iOS / Android 终端用户的真实浏览器中均能正确显示 (系统内置 emoji 字体)
- 所有数据均为 `seed.py` 自动生成的脱敏样本, 与真实患者无关
