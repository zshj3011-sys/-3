# MedMind Nexus 管理员手册

> 面向医院信息科 / 院长办 · 配套页面: `MedMindNexus/admin/`

## 一、运营驾驶舱 (dashboard.html)

### 1.1 KPI 卡片
- **今日门诊量** · 同比环比
- **在院人数** · 床位使用率
- **今日营收** · 实时刷新
- **DRG 盈亏** · 本月累计
- **AI 使用率** · 医生 AI 功能使用频次

### 1.2 30 天趋势图
- 门诊量曲线
- 收入曲线
- AI 调用次数曲线

### 1.3 预警弹窗
系统自动提示:
- 床位使用率 >95% (床位紧张)
- DRG 累计亏损 (财务风险)
- AI 异常调用激增 (可能滥用)

## 二、DRG/DIP 控费 (drg.html) ⭐ 核心

### 2.1 病案列表
- 按医保类型/科室/医生筛选
- 显示: 病案号 / 患者 / 主诊断 / DRG 编码 / 支付标准 / 实际成本 / **盈亏**

### 2.2 单病案 DRG 预测
输入主诊断 + ICD-10 + 手术编码 + 预计成本, AI 返回:
- DRG 分组编码 (e.g. FB29)
- 医保支付标准
- 预测实际成本
- **盈亏** (绿色 / 黄色 / 红色三级)
- **优化建议** (用药结构 / 检查项 / 住院日)

### 2.3 风险等级说明
- 🟢 **绿色**: 盈利, 病案合规
- 🟡 **黄色**: 微亏 (-5% 内), 建议优化
- 🔴 **红色**: 严重亏损 (-10% 以上), 需重点审查

## 三、医疗质控 (quality.html)

### 3.1 6 维雷达图
- 病历完整性
- 处方合理性
- 检查必要性
- 抗生素管控
- 院感率
- 患者满意度

### 3.2 异常病历清单
自动列出:
- 24h 未完成的病历
- 缺主诉 / 缺诊断的病历
- ICD-10 编码错误的病历

## 四、AI 价值分析 (ai-analytics.html)

展示:
- AI 节省的医生工作时长
- AI 推荐采纳率 (诊断/处方)
- AI 减少的误诊数
- ROI: AI 投入 vs 节省人力成本

## 五、账号管理 (后端 API)

通过 `/v1/admin/users` 系列 API:
- 添加新医生账号
- 重置密码
- 启用/禁用账号
- 分配角色: `doctor` / `pharmacist` / `admin` / `researcher`

## 六、审计日志

所有写操作都记录在 `audit_logs` 表:
- 谁 (user_id / username)
- 何时 (created_at)
- 何 IP (ip_address)
- 做了什么 (action / resource_type / resource_id)
- 结果 (success / failure)

满足**等保三级**要求, 留存 ≥180 天。

## 七、数据备份

### 7.1 SQLite (开发/小医院)
```bash
cp medmind-backend/data/medmind.db /backup/medmind-$(date +%Y%m%d).db
```

### 7.2 PostgreSQL (生产)
```bash
docker exec medmind-pg pg_dump -U medmind medmind > /backup/medmind-$(date +%Y%m%d).sql
```

**建议**: 每日凌晨 2 点自动备份, 保留 30 天。

## 八、性能调优

| 指标 | 目标 | 监控方式 |
|---|---|---|
| API P95 响应 | <500ms | Prometheus + Grafana |
| AI 调用 P95 | <8s | `audit_logs` 统计 |
| DB 连接池 | <80% | PG `pg_stat_activity` |
| 并发用户数 | 100+ | Nginx `access.log` |
