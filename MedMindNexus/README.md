# MedMind Nexus 医智中枢 · 最终交付版（v1.0）

> 面向中小医疗机构的 AI 原生智能体平台 —— 四端联动的医疗 AI 产品

## 🚀 如何使用

**第一步**：双击打开 `sitemap.html` ——这是为客户准备的**全产品总览页**，可以一眼看到所有 18 个页面、按"官网/患者端/医生端/管理端/科研端"分组卡片展示，点任意卡片直接进入。

**或者**：

- 想看产品介绍 → 打开 `index.html`
- 想跟着教程演示 → 打开 `demo-guide.html`

> **建议浏览器**：Chrome / Edge / Safari 最新版（管理端和科研端的图表使用 `cdn.jsdelivr.net` 上的 Chart.js，首次打开需联网；其他页面纯本地运行）。

## 🌟 主要特性

### 1. 产品总览页（sitemap.html）★ 推荐第一站
- 18 个页面一张图全部呈现
- 按四端分组、核心模块带 ⭐ 标记
- 任意卡片点击直达，方便给客户演示

### 2. 官网首页（index.html）
- Hero 区（含动态浮动卡片演示）
- 3 大核心差异化
- 四端入口
- 12 项技术栈（深色区）
- 3 档定价方案
- 联系我们 CTA

### 3. 患者端（patient/index.html）
- 手机外壳 + 5 个子页面 SPA 切换
- **AI 预问诊**：可交互的多轮对话，5 个问题后自动生成 SOAP 摘要
- **报告 AI 解读**：点击上传后展示血脂报告 + AI 通俗解读
- 智能分诊、用药提醒、健康档案

### 4. 医生端 ⭐ 核心
- **AI 诊间助手**：自动播放医患对话的实时语音转写动画，可点击"AI 生成草稿"自动填充 SOAP 病历
- 右侧 AI 实时推送：诊断建议 + 检查推荐 + 用药建议 + 指南依据
- 完整的医生工作流：工作台 → 诊间 → 病历 → 诊断 → 处方 → 质控

### 5. 管理端（深色驾驶舱）
- 含 11 张交互式 Chart.js 图表（折线、饼图、雷达、柱状图）
- DRG/DIP 控费：超支病案预警、AI 优化建议、ROI 趋势
- 医院核心 KPI 一图掌控

### 6. 科研端
- 文献检索：5 篇真实风格的高质量文献条目 + AI 摘要
- 统计分析：完整的 R 代码 + Kaplan-Meier 曲线 + Cox 回归结果
- 标书生成：完整的国自然标书 5 大章节
- 论文润色：中英对照 5 句润色对比 + AI 选刊推荐

## 💡 演示要点（约 8-10 分钟）

直接打开 `demo-guide.html` 跟着 5 个步骤走，也可以参考下面顺序：

1. 从 **sitemap.html** 一目了然 → 切到 **index.html** 介绍产品定位
2. 点击 **"医生工作台"** → 进入 **"AI 诊间助手"**，看实时语音转写动画（核心亮点）
3. 切换到 **"管理驾驶舱"** → **"DRG 控费"**，展示数据可视化能力
4. 进入 **"患者小程序"**，让客户体验 AI 预问诊对话
5. 最后到 **"科研端 → 标书生成"**，展示给医生客户带来的科研价值

## ⚠️ 说明

此版本为**前端产品原型 Demo**，用于：
- 向客户/投资人/合作方展示产品形态与功能流程
- 营销路演与方案讲解
- 申请软件著作权时作为界面截图来源
- 作为后端开发的前端蓝本

如需上线生产，需补充：
- 后端微服务（FastAPI + PostgreSQL + Milvus）
- 真实大模型对接（DeepSeek-R1 Medical / 通义医疗）
- HIS/LIS/PACS 系统集成
- 等保三级合规改造
- 真实语音 ASR（Web Speech API / Whisper）
