# MedMind Nexus 运维部署手册

> 面向医院信息科 / DevOps · 生产部署完整指南

## 一、部署架构

```
┌─────────────────────────────────────────┐
│  Nginx (443/HTTPS) + WAF                │
│  ├─ /  → 前端静态资源 (MedMindNexus)    │
│  ├─ /v1/* → FastAPI 后端 :8000          │
│  └─ /ws/* → WebSocket 后端 :8000         │
└─────────────────────────────────────────┘
                    │
        ┌───────────┼───────────┐
        │           │           │
   ┌────▼───┐  ┌───▼────┐  ┌───▼──────┐
   │ Backend│  │  Redis │  │PostgreSQL│
   │ FastAPI│  │ Cache  │  │   16     │
   │ :8000  │  │ :6379  │  │  :5432   │
   └────┬───┘  └────────┘  └──────────┘
        │
   ┌────▼────────────────┐
   │  LLM 网关 (按需)      │
   │  DeepSeek / 通义 / 智谱 │
   └─────────────────────┘
```

## 二、最小部署 (单机, 适合 5 医生以下小诊所)

### 2.1 服务器规格
- CPU: 4 核
- 内存: 8 GB
- 硬盘: 100 GB SSD
- 操作系统: Ubuntu 22.04 LTS / CentOS 8

### 2.2 Docker Compose 一键启动
```bash
git clone <your-repo> medmind
cd medmind/medmind-backend
cp .env.example .env
# 编辑 .env 设置: SECRET_KEY / LLM_PROVIDER / DATABASE_URL
docker compose --profile prod up -d
```

启动后访问:
- http://your-server:8000/docs · API 文档
- http://your-server:8000/web/sitemap.html · 前端入口

### 2.3 配置 Nginx 反向代理 (HTTPS)
```nginx
server {
  listen 443 ssl http2;
  server_name your-hospital.com;

  ssl_certificate     /etc/ssl/certs/medmind.crt;
  ssl_certificate_key /etc/ssl/private/medmind.key;

  client_max_body_size 50M;  # 报告 OCR 上传需要

  location / {
    proxy_pass http://127.0.0.1:8000;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
  }

  # WebSocket 必须的 Upgrade 头
  location /v1/ws/ {
    proxy_pass http://127.0.0.1:8000;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    proxy_read_timeout 600s;
  }
}
```

## 三、中型部署 (100+ 用户)

### 3.1 服务器规格
- App 服务器: 8 核 16 GB × 2 (负载均衡)
- DB 服务器: 8 核 32 GB + 500 GB SSD (PostgreSQL)
- Redis: 4 核 8 GB
- Nginx: 4 核 8 GB + WAF

### 3.2 多实例启动
```bash
# 4 个 worker 进程
uvicorn app.main:app --workers 4 --host 0.0.0.0 --port 8000

# 或用 gunicorn
gunicorn app.main:app -w 4 -k uvicorn.workers.UvicornWorker --bind 0.0.0.0:8000
```

### 3.3 PostgreSQL 调优
```sql
-- postgresql.conf
shared_buffers = 8GB
effective_cache_size = 24GB
work_mem = 64MB
maintenance_work_mem = 2GB
max_connections = 200
```

## 四、备份策略

### 4.1 数据库备份
```bash
# /etc/cron.d/medmind-backup
0 2 * * * postgres pg_dump -Fc medmind > /backup/medmind-$(date +\%Y\%m\%d).dump
0 3 * * 0 postgres find /backup -name "medmind-*.dump" -mtime +30 -delete
```

### 4.2 灾备
- 异地双活: 主备库流复制 (`primary_conninfo`)
- 增量 WAL 归档到对象存储 (MinIO / S3)
- RPO < 5 分钟 · RTO < 30 分钟

## 五、监控告警

### 5.1 Prometheus 指标
后端已内置 `/metrics` (需取消注释 `prometheus-fastapi-instrumentator`)

关键告警规则:
```yaml
- alert: HighErrorRate
  expr: rate(http_requests_total{status=~"5.."}[5m]) > 0.05
  for: 2m

- alert: SlowAPI
  expr: histogram_quantile(0.95, http_request_duration_seconds_bucket) > 1
  for: 5m

- alert: HighMemory
  expr: process_resident_memory_bytes > 4e9
  for: 5m
```

### 5.2 日志聚合
- 应用日志: loguru → JSON → Loki/ELK
- Nginx 访问日志: 按天切割, 保留 90 天
- 审计日志: PG `audit_logs` 表, 保留 180 天

## 六、灰度发布

```bash
# 1. 构建新版镜像
docker build -t medmind-backend:v1.1.0 .

# 2. 蓝绿部署: 启动新版到 :8001
docker run -d -p 8001:8000 --name medmind-v1.1.0 medmind-backend:v1.1.0

# 3. Nginx 切流量 (5%/25%/50%/100%)
# upstream 配置 weight=...

# 4. 观察 30 分钟无异常后, 关闭旧版
docker stop medmind-old && docker rm medmind-old
```

## 七、应急预案

| 故障 | 应急步骤 |
|---|---|
| 后端 5xx 飙升 | 1) `docker logs` 查日志 2) 检查 DB 连接 3) 回滚版本 |
| DB 连接耗尽 | 1) `SELECT pg_terminate_backend(...)` 杀长事务 2) 重启 PG 3) 扩 max_connections |
| 磁盘满 | 1) 清理旧日志 2) 清理旧备份 3) 扩盘 |
| LLM 调用全失败 | 1) 切回 `LLM_PROVIDER=mock` 2) 检查 API key/配额 3) 切备用供应商 |
| WebSocket 大量断连 | 1) 检查 Nginx `proxy_read_timeout` 2) 检查防火墙长连接策略 |

## 八、合规要点

### 8.1 等保三级
- 数据传输: TLS 1.3
- 数据存储: 数据库 TDE 加密
- 数据访问: 所有写操作 audit_logs 留痕 ≥180 天
- 身份认证: JWT + MFA (TOTP, schema 已预留)
- 角色权限: 5 角色 RBAC

### 8.2 数据脱敏
- 患者列表对**科研角色**自动脱敏:
  - 姓名 → 张** / 李**
  - 身份证 → 110***********1234
  - 手机 → 138****1234

### 8.3 数据出境
**严禁**: 患者原始数据不得通过公网 API 调用境外大模型
**建议**: LLM_PROVIDER 优先 DeepSeek/通义/智谱 (国内合规)
