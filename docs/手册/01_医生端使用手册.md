# MedMind Nexus 医生端使用手册

> 面向临床医生 · 5 分钟上手 · 配套页面: `MedMindNexus/doctor/`

## 一、登录

1. 打开浏览器, 访问 `http://your-server:8000/web/login.html`
2. 输入医生工号和密码 (或测试账号 `dr_zhang` / `doctor123`)
3. 登录成功自动跳转到工作台

## 二、工作台 (workbench.html)

工作台显示:
- **今日预约** · 患者列表 + 主诉摘要 + 状态
- **未签病历** · 提醒待补充的病历
- **快捷工作流** · 一键进入 AI 诊间、AI 诊断、处方审核

## 三、AI 诊间助手 (consultation.html) ⭐ 核心

### 3.1 接诊流程
1. 从工作台点击患者 → 进入诊间页
2. 患者基础信息自动加载 (年龄/性别/过敏史/既往史)
3. **开始录音** (浏览器要求麦克风权限) 或 **手动输入主诉**
4. 实时显示 AI 转写文字
5. 接诊结束点击"生成 SOAP 草稿"

### 3.2 SOAP 草稿审核
AI 自动生成 4 段:
- **S** 主观: 主诉 / 现病史
- **O** 客观: 查体 / 检验 / 检查
- **A** 评估: 诊断 (含 ICD-10) / 鉴别诊断
- **P** 计划: 治疗方案

每段都可手动编辑。系统会显示**置信度** + **引用知识库依据**, 置信度 <60% 自动标记"建议医生复核"。

### 3.3 提交病历
- 点击 **"保存草稿"** → 病历进入 `draft` 状态
- 点击 **"医师签名"** → 病历进入 `signed` 状态, 不可再修改

## 四、AI 诊断辅助 (diagnosis.html)

输入主诉 + 症状 + 患者基本信息, AI 返回:
- **主诊断** (含 ICD-10 + 概率 + 循证依据 + 反对依据)
- **3 个鉴别诊断**
- **建议检查项**

✅ 4 层幻觉防护:
1. Prompt 约束: 禁止编造 ICD/药品
2. JSON Schema: 严格校验输出
3. 引用回溯: 每条结论必须有 citation
4. 置信度阈值: <0.6 标"需复核"

## 五、处方审核 (prescription.html)

医生开方时, 系统自动:
- 检查双抗血小板叠加 (出血风险)
- 检查药物相互作用 (e.g. 他汀 + 大环内酯)
- 检查剂量合规 (按肝肾功能调整)
- 检查过敏史冲突

**审核评分** 0-100, ≥80 分允许签发, <80 分弹窗提醒。

## 六、病历质控 (quality.html)

对每份已签病历:
- 完整性评分 (主诉/现病史/诊断/处方是否齐全)
- 规范性评分 (ICD-10 编码是否准确)
- 时效性评分 (是否 24h 内完成)

雷达图直观展示 6 个维度评分。

## 七、键盘快捷键

| 键 | 功能 |
|---|---|
| Ctrl+S / Cmd+S | 保存当前病历草稿 |
| Ctrl+Enter | 提交并签名 |
| Esc | 关闭当前对话框 |
| F1 | 打开帮助 |

## 八、常见问题

**Q: AI 转写不准确怎么办?**
A: 可手动修正后再点"重新生成 SOAP"。AI 会基于您修正的版本重新生成。

**Q: AI 推荐的诊断我不认同?**
A: 完全可以采用您自己的诊断, AI 仅作参考。可在备注中说明理由。

**Q: 病历签名后能否修改?**
A: 不能。如发现错误需通过"病历修正申请"流程, 留痕审计。

**Q: 后端临时断开怎么办?**
A: 系统会自动提示"演示模式", 关键页面保留本地草稿, 联网后可同步。
